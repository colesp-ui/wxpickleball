# WX Pickleball

Next.js website for Woods Cross High School Pickleball.

## Deploy on Vercel

1. Upload these files to the `colesp-ui/wxpickleball` GitHub repository.
2. In Vercel, import that repository.
3. Vercel should detect Next.js automatically.
4. Deploy.
5. Connect `wxpickleball.com` to the deployed Vercel project.

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000

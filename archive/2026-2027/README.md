# Archived WX Pickleball “Play This Season” page — 2026–2027

Archived on October 29, 2026, after player selection for the season was complete.

The original files are preserved here, outside the Next.js `app/` directory, so `/play` no longer publishes the registration and tryouts page:

- `page.js`: full page (evaluations, selection, costs, benefits, interest form)
- `layout.js`: page-specific layout
- Root `app/template.js` includes enhancements originally used by this page.

To restore for a future season:
1. Copy the files to `app/play/page.js` and `app/play/layout.js`.
2. Update the season dates, fees, form links and selection details.
3. Restore the homepage and navigation links to `/play` once new-season details are ready.

The original 2026–2027 material is preserved unchanged.
